Agentic 模型 · 会调用工具，也会根据结果调整

选工具、调参数、看仿真，直到满足要求。

02 / 模型怎么做事

想一步，做一步，看结果，再调整。

工程师给出目标，Agent 调用工具完成任务，并根据反馈继续调整。

人工操作

工程师 → EDA 工具 → 看结果，再手动调整

Agent 方式

工程师定目标 → Agent → OPC / 仿真 / 检查工具 → 结果反馈给 Agent ↺

ReAct 就是下面这个循环：判断 → 调用工具 → 看结果 → 再判断。

仿真里的线头比目标短。先判断：是修正不足，还是当前工艺条件下难以印出？

OPC 软件内部完成数值优化；模型在外层选择路线、设置配方、判断是否换方案。工程师定义验收要求并做最终判断。
Agentic 能力：根据工具反馈把任务往前推进02 / 07
03 / 数据起什么作用

一条数据，记录一次完整的解题过程。

记录模型如何拆解工程师的目标、调用 EDA 工具、根据结果调整，以及最终是否达标。

01 / 任务

要达到什么

输入图形、目标指标、允许花多少次尝试。

02 / 环境

能用什么

工艺模型、图层、软件、可调参数和运行限制。

03 / 过程

具体怎么做

模型发出的消息、工具调用、参数和真实返回结果。

04 / 结果

到底好不好

最终掩模、仿真图形、指标和独立验收结论。

训练从好过程里学习评测在新任务上检验改进从失败里发现短板
要让模型学会指挥工具，就要记录“怎么选、怎么做、看到什么、为什么调整”。
Trace：实际发生过的消息与调用记录03 / 07
04 / 数据的三个标准

做对、见得广、确实做过。

01

质量

要求清楚，结果可靠。
有明确目标、有最终提交，也能重新检查。

不只看误差变小：还要看有没有桥连、断线、缺孔，是否满足掩模规则和预算。

02

多样性

换图形，也换问题。
覆盖不同工艺、工具、难度和失败原因。

按类别提前分配任务，限制相似图形的数量；同一设计切出的相似区域分组管理。

03

真实性

消息、调用、结果能对得上。
指标来自真实软件输出，不靠模型自报。

保留原始消息、配方和输出；独立重算。没有证据的结果，保留为“未知”。

成功和失败都可以保留，但必须知道成功在哪、失败在哪04 / 07
05 / 如何保证环境的多样性

不是只换一张图，
而是把任务条件真正换开。

图形不同

线头、拐角、孔阵列、疏密交界

图层不同

poly、metal、via 等；逐一确认适用性

工艺不同

光源、材料、曝光与焦距条件

路线不同

Calibre 的 nmOPC / nmCLOPC / PXOPC

任务不同

减小边缘误差、修缺陷、提高稳定性

约束不同

参数范围、尝试次数、运行时间

线头缩短，怎么补回来？

换不同线距与拐角结构，要求减小边缘误差，同时避免相邻线桥连。

任务设计示例；具体组合通过软件和工艺适用检查后才使用。
先按类别分配 → 再检查组合能否运行 → 最后统计实际覆盖。缺哪一类，就补哪一类。

三条 Calibre 路线不算三家软件；同一材料改几个光学参数，也不算几个独立校准工艺。

目标：让模型遇到新条件时仍然会做事05 / 07
06 / 如何让模型掌握 OPC

先学会调用，
再学会判断，最后学会迁移。

数据要进入训练与评测，才能知道模型是不是真的进步了。

01 / 学会做

用真实过程教模型

学习如何读任务、设参数、调用软件、看结果、提交掩模。保留有效调整和失败后的修正。

02 / 学会选

用独立检查给反馈

奖励在预算内满足要求的过程。不能只追求一个误差变小，同时忽略新缺陷或超预算。

03 / 学会换场景

用没见过的任务测试

把同源设计放在同一组，再划分训练与测试；检验新结构、新条件下是否仍能完成任务。

怎么判断进步？

任务达标率更高 · 相同预算下结果更好 · 工具调用更准确 · 遇到失败能恢复

循环改进：找出短板 → 补充对应数据 → 再训练 → 用新任务复测06 / 07
07 / 现在在做什么

先把数据管线做扎实，
再用它验证模型能否进步。

已有基础，正在补强

01已有 1,000 条历史任务及运行记录，保留原始版本。

02已验证三条 Calibre 路线的部分真实运行。

03正在补齐适用检查、预算、消息与结果对应、独立验收。

接下来怎么推进

01先解决环境稳定性和软件、工艺的适用问题。

02再做小批完整运行，检查数据是否可信、够多样。

03用合格数据训练，并在未见过的任务上检验提升。

让模型从“知道 OPC 是什么”，
走到“能把一个 OPC 任务做完、做好”。

已有任务不等于全部达标；当前仍有掩模规则未通过、改进效果不确定的控制案例。尚未证明训练后的能力提升，也不声称达到工厂签核水平。
